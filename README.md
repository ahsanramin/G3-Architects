# 🚀 G3 Architects - Ultra Premium SaaS Landing Page

Welcome to the **most detailed, premium, and ultra-modern** SaaS assignment solution for Programming Hero. This project is fully responsive, implements a sophisticated Theme Toggle system, and features advanced UI/UX design elements including glassmorphism, custom animations, smooth scrolling, and a functional carousel.

## 💎 Key Features (SaaS Level)

*   **Theme Toggle System:** Switch between Ultra-Light and Deep-Dark modes. Saves user preference.
*   **Advanced Animation:** Scroll-triggered reveals, floating blobs, animated counters, carousels, and smooth transitions.
*   **Complete SaaS Sections:**
    *   Hero with live stats and floating glass cards.
    *   Trusted Sponsors.
    *   Quick & Detailed Features.
    *   **Featured Projects.**
    *   **Top Experts** with social links.
    *   **Categories**.
    *   **How It's Works** (Step-by-step).
    *   **Why Clients Trust Us**.
    *   **Our Impact in Numbers** (Animated stats).
    *   **Client Testimonials** (Auto-rotating carousel).
    *   **Latest Tips & Articles**.
    *   **Choose Your Plan** (Pricing tiers).
    *   **Meet the Admin**.
    *   **Contact Us**.
    *   Bonus: **FAQ Section**.
*   **100% Responsive:** Optimized for Mobile, Tablets, and Desktop. Uses CSS Grid, Flexbox, and Media Queries.
*   **Custom UI Elements:** Custom scrollbar, glowing buttons, and a "Back to Top" button.
*   **External Resources:** FontAwesome Icons, Google Fonts (Poppins, Space Grotesk), Unsplash Images.
*   **Favicon Included:** Custom rocket favicon.

## 🛠️ Tech Stack

*   **HTML5:** Semantic Markup for accessibility.
*   **CSS3:** Advanced Styling, CSS Variables, Grid, Flexbox, Keyframes, Intersection Observer support.
*   **JavaScript (Vanilla):** Theme switching, Carousel Logic, FAQ Accordion, Animated Counters, Scroll-Progress Bar.
